\# 📚 Library Management System

A simple and responsive \*\*Library Management System\*\* webpage built using \*\*HTML5 and CSS3\*\*. This project provides a clean dashboard interface for managing books, members, and issued books.

\## ✨ Features

\- 📚 Library dashboard

\- 🧭 Responsive navigation bar

\- 📊 Statistics cards

\- Total Books

\- Available Books

\- Issued Books

\- Total Members

\- 🔍 Book search interface

\- 📖 Book list displayed in a table

\- 🟢 Available/🔴 Issued book status

\- 📱 Responsive design for desktop, tablet, and mobile devices

\- 🎨 Modern styling using pure CSS

\- 🦶 Footer section

\## 🛠️ Technologies Used

\- \*\*HTML5\*\* – Structure of the webpage

\- \*\*CSS3\*\* – Styling and responsive layout

\- \*\*CSS Grid\*\* – Dashboard cards

\- \*\*CSS Media Queries\*\* – Responsive design
